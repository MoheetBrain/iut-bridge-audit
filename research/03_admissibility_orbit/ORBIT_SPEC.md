# Conditional orbit specification

**SOURCE FACT [C003]:** LANA §9.2–9.3, p.46, supplies an existential compatibility target and a Teichmüller-space analogy. It does not define in those paragraphs a group whose action on S generates every permissible η.

**RECONSTRUCTION [C018; R_U07–R_U08]:** Until the admissibility and typing obligations are discharged, “orbit” is a name for the desired **image family**. If source-faithful Adm(D), a fixed equality type E_D and a well-defined construction F_D are established, then define

\[
F_D:\mathrm{Adm}(D)\longrightarrow E_D,\qquad
F_D(e,S)=\tau_{e,S}\circ\eta^{\mathrm{anab}}_{e,S},
\quad
\mathcal O_{\mathrm{anab}}(D)=\operatorname{im}(F_D).
\]

Only after proving that dependence factors through S is the shorter notation \(\{\eta^{\mathrm{anab}}_S:S\in\mathrm{Adm}(D)\}\) justified. E_D is intended to be the source-compatible oriented real-line isomorphisms inside a fixed linear-map type; its exact definition remains U07. Do not define E_D to force both different target pilots to be equal.

The conditional equivalence of `η_q ∈ image(F_D)` and `∃a, F_D(a)=η_q` is just the definition of image. It proves neither that F_D has the intended source domain nor that η_q lies in that image [C020, C023].
