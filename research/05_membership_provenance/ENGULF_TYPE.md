# What “engulf” is typed as

**Exact complete type not recovered.** The strongest source-grounded description before sQ5 is a **specialization/reconstruction claim about intertwining structures on one fixed abstract full prime-strip, expressed through poly-isomorphisms and cQ3/cQ4 formal diagram/category data**. This is a partially recovered D/C/E/H-type relation in the task's taxonomy. It is not yet an independently defined predicate `Engulf_pre`.

The decisive distinction is explicit in ELS §3.9, pp.143–144: a possibility is initially understood up to isomorphism within a collection that need not be a set. ELS §3.8 (NSsQ/LVsQ), p.140, reserves the coarse set-theoretic comparison for the closed loop followed by log-volume. ELS (Englf), p.155, is a pictorial description of fixed gluing plus enlargement; it supplies no new stand-alone object, morphism or membership definition.

| Candidate type | Finding |

| B: q-region contained in hull | Would be a useful sufficient certificate in one certified realization; no independent general derivation recovered here. Not imposed as necessary. |
| C: object in formal quotient category | cQ3 supplies a **pair** of local/global categories, not a fully specified universal quotient or an existence theorem for native q inside it. |

| F: containment after Rss | Rss and compatible values are defined. Such a scalar-class relation would not recover the lost unit/Galois structure. |
| G: scalar membership | Explicit in xi-f. Defining Englf this way merely names the target. |
| H: formal systems and reconstruction history | Essential: cQ3 local/global tuples, cQ4 log iterates, formal inverse systems, and ELS InOut/ItwOut enrichment. |

The actual original objects are: the full `F^{⊩▶×μ}`-prime-strip of IUT2 Definition 4.9(viii); its local Galois actions and Frobenius-like unit portions; local/global Frobenioids and localization maps; the fixed native q-pilot; the multiradial splitting-monoid action and tensor packet regions; the bounded-family hull; the weighted determinant; and the two local/global categories of cQ3, related to shifted copies through cQ4. Existing detailed dictionaries are [SQ3_TYPES](../04_closed_loop/SQ3_TYPES.csv), [SQ4_TYPES](../04_closed_loop/SQ4_TYPES.csv), and [formal quotient ledger](../04_closed_loop/FORMAL_QUOTIENT_LEDGER.csv).

In cQ3 an object of the local upper category has a structure poly-morphism to `det^M(phi(P_B))`, given by an automorphism orbit of a **linear** morphism. Local/global objects also have a global realified object and localization isomorphisms. These are real mathematical constraints. The text calls the resulting pair of categories a formal quotient; it does not give permission to replace it with the equivalence relation “has the same scalar”.

In ELS CCD, pp.159–160, `Y1 <- X -> Y2` persists as Y1 is enlarged. Commutation preserves the fixed gluing X. It does not, merely as a diagram identity, prove that the final enlargement contains Y2. The terminal assertion and its IUT instantiation require the Stp7 comparison. ELS FrgInv/GluDt, p.164, explain recovery modulo indeterminacies and the limited structure actually glued; they do not furnish a separately typed essential-image theorem for native q.
