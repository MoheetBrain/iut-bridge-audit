\[

Stage 13 instantiates this on a vertical MOD/TL comparison with the same `h`. It does not supply a horizontal non-realified number-field action map across `lambda`, nor the receiving specialization. ## Why repeated narrower reconstructions returned to the same boundary

The work increasingly retained units, labels, evaluation, weights and coupled choices. Each positive lemma had a local or conditional scope. No accepted theorem turned those retained data into an admitted native-marked bounded formal comparison. Moving from a quotient invariant to an arithmetic witness without a lift theorem repeatedly returned to the same gap. Another representation is useful only if it proves an actual lifting, calibration, effectivity or approximation proposition; adding names to a graph does not do so.

The exact information missing at the stop was **jointly admissible native marking + receiving normalization + bounded-output provenance**, or a weaker source-faithful numerical/approximation comparison replacing that triple. It was not merely an unrecognized field, a local point, or a missing elementary real inequality.
